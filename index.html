Uma equipe de exploradores militares investiga um posto avançado abandonado. Entre nas ruínas, combata os sentinelas e recupere os dados da expedição. Este protótipo usa renderização leve em Canvas para rodar no navegador.

◈ CAMPANHAMissão, combate, vida e munição.
◉ CONTROLES MOBILEJogue deitado com joystick e mira tátil.
⚡ LEVESem instalação; gráficos estilizados em tempo real.
Multiplayer: desconectado. Para partidas online, ambos precisam abrir o jogo publicado e usar o mesmo código de sala.

Nota: o modo P2P usa PeerJS via internet e depende de servidor de sinalização público; é um protótipo experimental, não um serviço de matchmaking dedicado. Nunca compartilhe dados pessoais no código da sala.
